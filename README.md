# houseing Website

Sabrina Residences is a two-section React landing page built with Vite and Lucide icons.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

The page uses the supplied SceneAI media URLs and Google Fonts. The language selector changes the selected preference. Agent, Partner, and Sign In are front-end placeholders for future destinations. The muted preview video retries interrupted playback and respects manual pause and reduced-motion preferences.
