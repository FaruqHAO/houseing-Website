# houseing Website

BAOSAT Housing is a two-section React landing page built with Vite and Lucide icons.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

The collection showcases illustrative residential concepts. Media includes SceneAI imagery and video, Unsplash photography, and two interior motion studies made from still photographs. Films play on demand and motion effects respect reduced-motion preferences.

The Layout Studio is a client-side concept planner. It saves one draft in local storage and exports an SVG. It has no server-side project storage or enquiry submission.
